# F-010: Cross-app form links must survive login without routing secrets

Scope: framework/appui · Domain: ui

- Trigger: Settings to Credential Store handoff required repetitive metadata entry. Existing AppUIUrlFields was available; reuse it rather than add per-page URL parsing.
- Prevention: declare field allowlists and validators, build links with the common API, initialize scoped fields only after provider defaults, never prefill secrets or submit automatically. Reject raw selectors and ambiguous duplicate fields. Preserve approved metadata through the owner login redirect, not arbitrary query values. Confirm destination before saving; require reentry of a secret if changing credential destination/auth metadata.
- Verification: credential browser_prefill.py validates actual page assets and shared runtime, ignored secret parameters, explicit confirmation/cancel and one save. Gateway regression checks login preservation and secret exclusion.
